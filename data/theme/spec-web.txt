00 · SUMMARY
Listing Performance Drawer · Bayut KSA
An agent opens My Listings, sees every listing's rank and quality score in the row, and clicks a row to open a right-side drawer that explains why that listing performs the way it does and what to fix. The drawer is one component for all nine listing cases: rank card, trend chart, fix list and upsells all read from the listing, so a perfect listing shows no fix list and a just-posted one shows an empty trend.

Appendix
Phase rule
The drawer explains and links out. It does not edit the listing: every fix card ends in a CTA that hands off to the existing edit or purchase flow, and nothing inside the drawer writes to the listing except Apply Signature and Refresh, which only trigger the rank-updating state.

07 · ACCEPTANCE CRITERIA
Verifiable without opening Figma. QA and the ticket cite these numbers.
07.1
Open the drawer
GIVEN
the Active tab with listings
WHEN
the user clicks anywhere in a row
THEN
the drawer opens from the right with that listing's rank, quality, fixes and upsells, and the page behind stays scrolled where it was
07.2
Reach the explainer without a listing
GIVEN
the Active tab
WHEN
the user clicks the info icon on the Performance or Quality column header
THEN
the generic explainer drawer opens, with no per-listing values anywhere in it
07.3
Rank updating
GIVEN
an open drawer on a listing with a rank
WHEN
the user applies Signature or taps Refresh
THEN
the rank tile shows the pulsing spark, the shimmer sweep and Your rank is being updated, the previous rank is hidden, and Views, Clicks and Leads keep their live values
07.4
Sorting
GIVEN
any sort option
WHEN
the user picks it
THEN
rows are replaced by skeletons with Sorting 65 listings for 4.5s, the page is locked, then the sorted rows rise in with a 90ms stagger, listings with no data last
07.5
Tab column sets
GIVEN
each of the five tabs
WHEN
the tab is active
THEN
the column set, timeline labels and row actions match section 03 for that tab, and no other tab's columns appear
07.6
Ad License filter swap
GIVEN
the Ad License Requests tab
WHEN
it becomes active
THEN
the filter bar shows Request ID, Deed Number, Status and Created On, listing filters are cleared, and the sort control and performance segment are hidden
07.7
Perfect score
GIVEN
a listing at 100% quality
WHEN
the drawer opens
THEN
no fix list renders and no Signature upsell renders
07.8
Reduced motion
GIVEN
prefers-reduced-motion: reduce
WHEN
any screen opens
THEN
all content is present at its end state with no animation, and no Lottie player is mounted: the last frame renders as a still
07.9
No internet
GIVEN
the list area on any tab
WHEN
the connection drops
THEN
the crossed-cloud state replaces the rows with Try Again, which reads Retrying for 1.5s, plus an I am back online link, and the ordinary empty state does not also render
07.10
TruCheck state
GIVEN
a row or card action bar
WHEN
the listing has a TruCheck state
THEN
the state reads as a 16px badge on the top-right corner of the TruCheck button, green tick verified, grey clock visit pending, grey plus eligible, red ! rejected, grey ! expired, the tooltip names the state, and off-plan carries no badge with the button disabled
07.11
Explainer reachability
GIVEN
the Active tab
WHEN
the user opens the score explainer
THEN
it opens from the banner after the second listing or from either column-header info icon, and it never shows per-listing values

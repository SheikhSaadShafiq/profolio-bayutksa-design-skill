Every screen the design system compiled, and every state of it — 361 states over 16 screens, 325 web files (1440) and 207 responsive files (375). Each screen’s page says what it is for, what it is made of, and how to reach each state, with the file to open.

Designing from a PRD? Search this instead of guessing a file name: node scripts/design-find.mjs "mark a daily rental as booked" lists the screens, states and components that match, best first, with their files. The same index is data/design-kb.json.

# Changelog — design-illustration

## [1.0.0] — 2026-10-01

### Added
- An inventory of the product's own art, and its measured style
  fingerprint (`references/style.md`): size, stroke, caps and joins,
  fills, palette, perspective, detail, people.
- Reuse by meaning before any new drawing.
- New SVG drawn inside the fingerprint, with colours only by reference to
  the palette, so it follows a theme. Every new piece is flagged
  `[new art]`.
- Alternative text for each picture, or marked decorative.
- `illustration.md`: each moment, reused or new, its file, placement and
  alternative text.

# Changelog — design-apple-hig

## [1.0.0] — 2026-10-01

### Added
- Navigation by need, for iPhone and iPad: tab bar, navigation stack,
  sidebar, sheet, menus, segmented control and search
  (`references/hig.md`).
- Modality, type mapped to Dynamic Type text styles, colour mapped to
  semantic roles with dark-mode values, layout (safe areas, margins, size
  classes), native controls and SF Symbols, feedback and haptics.
- A checklist. `hig.md` holds the structure chosen, the mappings, each
  issue with its fix, and SwiftUI or UIKit notes.
- The product's brand is kept and adapted to the platform: its accent as
  the tint, its voice and imagery.
